# IQOSFree

Автономний PWA-застосунок для поступової відмови від стіків, контролю часових інтервалів, відстеження етапів детоксикації організму та обліку витрат.

Живий сайт: https://mastrophot.github.io/IQOSFree/

## Можливості

- **Bio-Core 3.0 (Дерево стану):** детермінована математична модель здоров'я (`+10%/год` регенерації, штрафи `-5%` / `-10%`) та `5` стадій еволюції на основі історії.
- **Urge Surfing (`SOS · 60с`):** синхронізована дихальна вправа (`5с вдих / 5с видих`) для проходження гострої фази нікотинової тяги без зриву.
- **Контроль інтервалів і відкат (`Undo`):** таймер паузи з коректною обробкою багатогодинних інтервалів (`HH:MM:SS`) та 60-секундним вікном скасування помилкового кліку.
- **Аналітика без зовнішніх CDN:** власний HiDPI Canvas-графік (`День / Тиждень / 6 міс`, `Стіки / Гроші` у вибраній валюті `₴ / $ / €`) і теплова карта пікової активності.
- **100% офлайн та приватність:** строгий `Content-Security-Policy` (`script-src 'self'`), `0` зовнішніх скриптів, миттєве кешування через `Service Worker`, експорт та імпорт резервних копій у `.json`.
- **Чистий OLED (`#000000`):** `0%` фонового навантаження на GPU та автоматична пауза таймера у згорнутих вкладках.

## Локальний запуск

```bash
git clone https://github.com/mastrophot/IQOSFree.git
cd IQOSFree
python3 -m http.server 8080
```
